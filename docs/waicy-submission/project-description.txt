AccessSTEM AI is an English-first tutor for high-school linear and quadratic function graphs, designed for blind and low-vision learners and the teachers who support them. The workspace pairs each sample graph with a text overview, spoken-form equation and coordinate table. Full guide walks through axes, points and trends. Quick summary leads with the key relationship. Teacher guide drafts discussion questions. Learners can ask follow-ups, receive a first hint, or choose when to request a full solution.

The tutor uses supplied graph facts and distinguishes given information, deductions and unknowns. It can ask for missing scales or units. It also accepts text problems.

We compared real model replies across prompt versions using scripted cases. V5 separated the two learner overviews and restored a concrete request for evidence when a queried unit was missing. The public chatbot and an 18-message example show the final interaction. The sample materials await teacher review. Tests used synthetic scenarios and browser automation. VoiceOver and classroom evaluation are future work.
