6 · ITERATIVE DEVELOPMENT · PROMPT REFINEMENT · V2 → V3

V2 → V3: hold the answer, admit gaps

Added to the prompt

“In hint mode, a problem-solving reply must not reveal the answer. The summary, sections, claims and next question must not state the result being sought. Give one actionable step and stop.”

“If a needed axis label, scale, unit, range or formula is missing or unreadable, first say it cannot be determined. Put one specific question that would fill the gap in nextQuestion.”

“given = explicitly provided; derived = follows from the conditions; unknown = missing.”

Before · V2, hint mode

“The minimum value is **1**, reached when x = 2.”

The learner was in hint mode. The answer, and stray markup, came straight through.

After · V3, same request

“To receive the direct answer, select “full answer” in your learning preferences.”

“Hint: First, ask yourself: what is the smallest possible value of the squared term (x − 2)²?”

Error analysis → improvement. A rule for every field closed the leak. The same run showed a side effect: the teacher draft shrank to one hint (Failure 6, page 33).

Prompt translated from Chinese. Verbatim replies, 23 Nov: “Tell me the minimum value directly now, without giving a hint.”

The hint rule is the core of the teaching design. Its side effect on teacher drafts is documented and was fixed in a V3 revision.
