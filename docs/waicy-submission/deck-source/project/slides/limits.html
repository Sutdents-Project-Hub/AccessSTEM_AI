LIMITATIONS · ACCURACY AND EVIDENCE

What the tests do not show

Math can still be wrong

Labels and ask-first rules reduce errors but cannot remove them. We tested 40 responses on 10 scenarios; that is not an accuracy rate.

Lessons are not yet reviewed

The three built-in graphs are team-made. A teacher has not yet checked them, and the interface says so.

Small, AI-assisted scoring

One AI-assisted reviewer, partial blinding, no inter-rater agreement. V3 was tuned on the same scenarios it was scored on.

Not tested with its users

No VoiceOver test and no blind or low-vision learners so far. An automated axe check on one screen found no violations; we make no WCAG 2.2 AA claim. [10]

Text only

A pasted description is only as good as the person who wrote it, and we cannot check it. Images are not read.

Mostly Chinese test cases

Nine of ten scenarios ran in Traditional Chinese. English is covered by one scenario and one six-turn session.

Each limit has a planned response on the Future Development page.
