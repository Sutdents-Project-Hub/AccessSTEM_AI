7 · LIMITATIONS · ACCURACY AND EVIDENCE

What the tests do not show

The tutor can still slip

Math or instructions can go wrong on new tasks. Each new round has found slips (pages 35–36). One V5 hint jumps to the key value of x; others may remain.

Lessons are not yet reviewed

The three built-in graphs were created for this project. A teacher has not yet checked them, and the interface says so.

Small samples

The pilot was scored in one pass, partly blinded, with no human grading. V3 was tuned on those scenarios. V4–V5 checks use one reply per case.

Not tested with its users

No VoiceOver test and no blind or low-vision learners so far. Keyboard and viewport checks cover Chrome only; no WCAG 2.2 AA claim. [18]

Text only

A pasted description is only as good as the person who wrote it, and we cannot check it. Images are not read.

English replication

The initial scored pilot used mostly Chinese inputs. The English run reused the scenario designs. Held-out English cases remain open.
