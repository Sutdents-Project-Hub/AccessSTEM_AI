8 · FUTURE DEVELOPMENT · ALL ITEMS ARE PLANNED, NOT BUILT

From a tested prototype to a trusted tool

Next · before wider use

Gentler first hints, checked across repeated runs.

Teacher review of the three lessons, then update the labels.

Accessibility testing with VoiceOver, NVDA and TalkBack.

Hold-out evaluation: 36 new cases, two human raters, repeated runs.

Answer-leak validator that rejects hint-mode replies containing the target value.

Soon · with real users

Study with blind and low-vision students and their teachers, with consent and anonymized data, building on work such as VizAbility. [16]

Image input in two steps: the AI proposes graph facts, a person confirms.

Voice input and spoken math.

Later · wider reach

More visuals: bar and line charts, velocity–time graphs.

Companion outputs: audio graphs and tactile-ready descriptions.

Teacher tools: exportable lesson drafts and a shared, reviewed lesson library.

Privacy options: smaller or on-device models.

Each step answers a limitation: repeated runs → one reply per case · teacher review → unreviewed lessons · human raters and hold-out cases → small, tuned evaluation · user study → not tested with users · validator → answer leaks · image input → text-only.
