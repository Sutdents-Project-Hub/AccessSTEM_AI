Failures 2–5: what broke and what we changed

2 · Missing unit

Found. V1 refused to assume meters but asked a hypothetical height question instead of the missing information.

Change. Ask for the missing data in one specific question; add a “Respond to this question” button.

Result. V3 asks what y represents; the English session repeats this.

3 · Rate evidence

Found. Baseline, V1 and V2 told a student to read values from a graph with no readable scale.

Change. Two points give only an interval average (change in quantity ÷ change in time); a fixed rate needs a formula or stated condition.

Result. Terra: 3 of 3 re-tests complete. Luna: 1 of 2 omitted the formula.

4 · Language mix

Found. An English request gave an English summary but Chinese headings and body.

Change. The interface language is sent to the model and applies to every field.

Result. Six-turn English session with no mixing.

5 · Bad source IDs, stray markup

Found. Some replies cited IDs that map to nothing, or carried math wrappers and control codes.

Change. Source IDs validated; display text cleaned. Raw outputs untouched.

Result. Controlled adapter tests passed for source limits, cleaning, 429 and 502.

Raw replies for each item are in evidence/raw. Results describe re-tests, not general accuracy.
