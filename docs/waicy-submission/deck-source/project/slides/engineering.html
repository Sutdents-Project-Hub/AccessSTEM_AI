Choosing a model with the same final prompt

ModelMedianObservation (4 scenarios × 2 repeats)
Luna, low3.31 sHints and the English request withheld the answer. Rate answers asked for data.
Luna, medium3.84 sSame hint behavior. One rate answer mentioned only the interval average.
Terra, low2.79 sShorter hints. Both rate answers separated average from fixed rate.

Decision. In a three-repeat re-test of the rate scenario, Terra gave the formula and the average-versus-fixed distinction every time; Luna once did not. Terra with low reasoning became the demo default, and Luna can be selected by an environment variable.

Safeguards in the build

  • API key only on the server
  • Input length and role checks
  • Strict JSON schema for every reply
  • Source IDs validated; text cleaned
  • Requests set store = false
  • Provider errors shown, never faked

Final run, median response time (10 responses each, noisy): Baseline 5.1 s · V1 5.0 s · V2 5.4 s · V3 4.4 s.

Model comparison used 8 responses per model: a small-sample selection, not a benchmark.

Model names are the configured identifiers in the project. The comparison informed a practical choice for the demo; it does not rank the models in general.
